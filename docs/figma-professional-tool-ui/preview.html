subtitleInfoCollection - Professional Tool UI

Light Ops workstation direction for the PySide6 desktop app. This mirrors the planned Figma file while the Figma MCP quota is blocked.

01 Audit

现有功能入口

工作台、采集任务、字幕解析、历史记录、设置与维护。设计保留入口语义，但强化状态层级和任务可见性。

视觉问题

信息权重偏平均，长路径和日志可扫读性不足，危险操作需要更明确隔离，1320x840 下要减少异常滚动和留白。

实现不变量

不改变采集/解析业务逻辑，不改 worker 信号，不改 storage/config 数据形状，后续只调整 UI helper、样式和布局。
